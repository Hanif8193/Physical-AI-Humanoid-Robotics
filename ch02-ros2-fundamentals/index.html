The Robotic Nervous System (ROS 2 Fundamentals)

Overview​

ROS 2 (Robot Operating System 2) is the nervous system of modern robots — a middleware framework that connects sensors, processors, and actuators through a publish-subscribe communication model. This chapter teaches you to build ROS 2 nodes, communicate via topics and services, and create Python-based robot agents using rclpy.

Learning Outcomes​

By the end of this chapter, you will be able to:

  1. Implement ROS 2 nodes in Python using rclpy that publish and subscribe to topics.
  2. Design a multi-node communication architecture using topics, services, and actions.
  3. Build a URDF model describing a simple humanoid robot's physical structure.

Concepts​

2.1 What Is ROS 2?​

ROS 2 is not an operating system — it's a set of software libraries and tools for building robot applications. It provides:

  • Node-based architecture: Modular, reusable software components
  • Publish/Subscribe messaging: Decoupled inter-process communication
  • Service/Client pattern: Request-response interactions
  • Action interface: Long-running goal-oriented tasks with feedback
  • DDS transport: Industry-standard, real-time capable messaging

2.2 Core Concepts​

Nodes​

A node is the fundamental execution unit in ROS 2. Each node is a process that:

  • Has a unique name (/camera_node, /motor_controller)
  • Publishes and/or subscribes to topics
  • Provides and/or calls services
  • Has lifecycle states: unconfigured → inactive → active → finalized
import rclpy
from rclpy.node import Node

class MyRobotNode(Node):
    def __init__(self):
        super().__init__('my_robot_node')
        self.get_logger().info('Node started!')

def main():
    rclpy.init()
    node = MyRobotNode()
    rclpy.spin(node)
    rclpy.shutdown()

Topics​

Topics are named message buses for one-way, many-to-many communication:

Publisher (sensor) ──► /lidar_scan ──► Subscriber (planner)
                                   └──► Subscriber (mapper)
from sensor_msgs.msg import LaserScan
from geometry_msgs.msg import Twist

class SensorNode(Node):
    def __init__(self):
        super().__init__('sensor_node')
        # Publish LiDAR data at 10 Hz
        self.publisher = self.create_publisher(LaserScan, '/lidar_scan', 10)
        self.timer = self.create_timer(0.1, self.publish_scan)

    def publish_scan(self):
        msg = LaserScan()
        msg.header.stamp = self.get_clock().now().to_msg()
        # ... fill scan data
        self.publisher.publish(msg)

Services​

Services provide request-response communication:

from std_srvs.srv import SetBool

class GripperNode(Node):
    def __init__(self):
        super().__init__('gripper_node')
        self.srv = self.create_service(SetBool, '/grip', self.grip_callback)

    def grip_callback(self, request, response):
        if request.data:
            self.get_logger().info('Closing gripper')
        else:
            self.get_logger().info('Opening gripper')
        response.success = True
        response.message = 'Gripper state changed'
        return response

Actions​

Actions are for long-running tasks with feedback (navigation, manipulation):

from nav2_msgs.action import NavigateToPose

# Action client sends goal, receives periodic feedback, and final result

2.3 ROS 2 Graph Architecture​

A real robot system looks like this:

/camera_node ──► /image_raw ──► /perception_node ──► /detected_objects
                                                  └──► /depth_estimate

/lidar_node ──► /scan ──► /slam_node ──► /map
                       └──► /obstacle_detector

/nav_node ◄── /map ◄── /slam_node
/nav_node ──► /cmd_vel ──► /motor_controller

2.4 URDF — Describing Your Robot​

URDF (Unified Robot Description Format) is XML that describes a robot's:

  • Links: Rigid bodies (chassis, arm, hand)
  • Joints: Connections between links (revolute, prismatic, fixed)
  • Visual/Collision: Geometry for rendering and physics
<?xml version="1.0"?>
<robot name="humanoid_base">
  <link name="base_link">
    <visual>
      <geometry>
        <box size="0.3 0.2 0.6"/>
      </geometry>
    </visual>
    <collision>
      <geometry>
        <box size="0.3 0.2 0.6"/>
      </geometry>
    </collision>
    <inertial>
      <mass value="20.0"/>
      <inertia ixx="0.5" ixy="0" ixz="0" iyy="0.5" iyz="0" izz="0.1"/>
    </inertial>
  </link>

  <link name="right_arm">
    <visual>
      <geometry><cylinder length="0.4" radius="0.03"/></geometry>
    </visual>
  </link>

  <joint name="right_shoulder" type="revolute">
    <parent link="base_link"/>
    <child link="right_arm"/>
    <origin xyz="0.15 0 0.25" rpy="0 0 0"/>
    <axis xyz="0 1 0"/>
    <limit lower="-1.57" upper="1.57" effort="100" velocity="1.0"/>
  </joint>
</robot>

2.5 rclpy — Python Agent Development​

rclpy enables writing ROS 2 nodes in Python, ideal for AI agent logic:

#!/usr/bin/env python3
"""
Simple obstacle-avoiding agent using rclpy.
"""
import rclpy
from rclpy.node import Node
from sensor_msgs.msg import LaserScan
from geometry_msgs.msg import Twist
import math

class ObstacleAvoidAgent(Node):
    def __init__(self):
        super().__init__('obstacle_avoid_agent')
        self.scan_sub = self.create_subscription(
            LaserScan, '/scan', self.scan_callback, 10
        )
        self.cmd_pub = self.create_publisher(Twist, '/cmd_vel', 10)
        self.min_distance = 0.5  # meters

    def scan_callback(self, msg: LaserScan):
        # Find minimum distance in front (±30 degrees)
        front_angles = msg.ranges[len(msg.ranges)//2 - 15 : len(msg.ranges)//2 + 15]
        min_dist = min(r for r in front_angles if not math.isinf(r))

        cmd = Twist()
        if min_dist < self.min_distance:
            # Obstacle detected — turn right
            cmd.angular.z = -0.5
            self.get_logger().warn(f'Obstacle at {min_dist:.2f}m — turning')
        else:
            # Clear ahead — move forward
            cmd.linear.x = 0.3

        self.cmd_pub.publish(cmd)

Lab​

Lab A: Your First ROS 2 Node 💻 CPU-ONLY​

Prerequisites:

  • ROS 2 Humble installed (see Chapter 1 Lab)
  • Python 3.10+

Instructions:

# Step 1: Create a ROS 2 workspace
mkdir -p ~/ros2_ws/src
cd ~/ros2_ws/src

# Step 2: Create a Python package
ros2 pkg create --build-type ament_python --dependencies rclpy std_msgs my_robot_agent

# Step 3: Write a publisher node
cat > ~/ros2_ws/src/my_robot_agent/my_robot_agent/talker.py << 'EOF'
import rclpy
from rclpy.node import Node
from std_msgs.msg import String

class Talker(Node):
    def __init__(self):
        super().__init__('talker')
        self.pub = self.create_publisher(String, 'chatter', 10)
        self.timer = self.create_timer(1.0, self.publish)
        self.count = 0

    def publish(self):
        msg = String()
        msg.data = f'Hello Physical AI! Count: {self.count}'
        self.pub.publish(msg)
        self.get_logger().info(f'Published: {msg.data}')
        self.count += 1

def main():
    rclpy.init()
    rclpy.spin(Talker())
    rclpy.shutdown()
EOF

# Step 4: Build and run
cd ~/ros2_ws
colcon build --packages-select my_robot_agent
source install/setup.bash
ros2 run my_robot_agent talker

[INFO] [talker]: Published: Hello Physical AI! Count: 0
[INFO] [talker]: Published: Hello Physical AI! Count: 1

Exercises​

  1. Implement a subscriber node that listens to /chatter and echoes back messages to /chatter_echo. Test it with the talker node from Lab A.

  2. Create a service called /toggle_light that accepts a SetBool request and logs "Light ON" or "Light OFF" based on the request value.

  3. Design a URDF for a simple 2-wheeled differential drive robot with a LiDAR sensor mounted on top. Include at least: base_link, left_wheel, right_wheel, and lidar joints.

Summary​

Key takeaways from this chapter:

  • ROS 2 nodes are the fundamental unit of robot software — independent, reusable processes
  • Topics enable decoupled publish/subscribe communication between nodes
  • Services provide request-response interactions for discrete operations
  • Actions handle long-running tasks (navigation, manipulation) with feedback
  • URDF describes the physical structure of your robot in XML
  • rclpy lets you write intelligent robot agents in Python
