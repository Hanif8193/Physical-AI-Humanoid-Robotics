## Entities

### 1. Chapter (MDX Frontmatter + File System)

**Source of truth**: `docs/` directory in Docusaurus repo

| Field | Type | Constraints |
|-------|------|-------------|
| `title` | string | Required, max 120 chars |
| `module` | enum | `ros2` \| `digital-twin` \| `isaac` \| `vla` \| `capstone` |
| `difficulty` | enum | `beginner` \| `intermediate` \| `advanced` |
| `hardware_tags` | string[] | Min 1; values: `RTX-LOCAL`, `JETSON-ORIN`, `CLOUD`, `CPU-ONLY` |
| `personalization_supported` | boolean | Default: true |
| `translation_supported` | boolean | Default: true |
| `order` | integer | Sort order within module |
| `slug` | string | Auto-derived from file path |

### 2. User (Neon Postgres — table: `users`)

| Field | Type | Constraints |
|-------|------|-------------|
| `id` | uuid | PK, auto-generated |
| `email` | string | Unique, required |
| `name` | string | Optional |
| `created_at` | timestamp | Auto |
| `updated_at` | timestamp | Auto |

### 3. UserProfile (Neon Postgres — table: `user_profiles`)

| Field | Type | Constraints |
|-------|------|-------------|
| `user_id` | uuid | FK → users.id, PK |
| `software_background` | string | e.g., "Python, ROS 2 beginner" |
| `hardware_background` | string | e.g., "Has RTX 3080, no Jetson" |
| `experience_level` | enum | `beginner` \| `intermediate` \| `expert` |
| `preferred_language` | enum | `en` \| `ur` |
| `created_at` | timestamp | Auto |
| `updated_at` | timestamp | Auto |

### 4. Session (Neon Postgres — managed by Better-Auth)

| Field | Type | Constraints |
|-------|------|-------------|
| `id` | uuid | PK |
| `user_id` | uuid | FK → users.id |
| `token` | string | Hashed session token |
| `expires_at` | timestamp | Required |
| `created_at` | timestamp | Auto |

### 5. ChunkEmbedding (Qdrant Cloud — collection: `textbook_chunks`)

| Field | Type | Constraints |
|-------|------|-------------|
| `id` | uuid | Auto-generated by Qdrant |
| `vector` | float32[1536] | `text-embedding-3-small` embedding |
| `payload.chapter_slug` | string | Source chapter slug |
| `payload.module` | string | Module identifier |
| `payload.section` | string | Section heading |
| `payload.text` | string | Original chunk text (max 512 tokens) |
| `payload.chunk_index` | integer | Order within chapter |

### 6. ChatSession (Neon Postgres — table: `chat_sessions`)

| Field | Type | Constraints |
|-------|------|-------------|
| `id` | uuid | PK |
| `user_id` | uuid | FK → users.id, nullable (anonymous) |
| `chapter_slug` | string | Context chapter, nullable (global) |
| `created_at` | timestamp | Auto |

### 7. ChatMessage (Neon Postgres — table: `chat_messages`)

| Field | Type | Constraints |
|-------|------|-------------|
| `id` | uuid | PK |
| `session_id` | uuid | FK → chat_sessions.id |
| `role` | enum | `user` \| `assistant` |
| `content` | text | Required |
| `citations` | jsonb | Array of `{chapter_slug, section, text}` |
| `selected_context` | text | Nullable; user-selected text |
| `created_at` | timestamp | Auto |

## Relationships

```
User ──── 1:1 ────> UserProfile
User ──── 1:N ────> Session (Better-Auth)
User ──── 1:N ────> ChatSession
ChatSession ──── 1:N ────> ChatMessage
Chapter (file) ──── 1:N ────> ChunkEmbedding (Qdrant)
```

## State Transitions

### Personalization Flow
```
Chapter (default) → [user clicks Personalize] → API call with user_profile
→ Personalized content (ephemeral, not persisted) → Displayed in UI
→ [user navigates away] → Reverts to default
```

### Translation Flow
```
Chapter (default) → [user clicks Translate to Urdu] → API call
→ Translated content cached in browser (TranslationCache)
→ [user clicks Show Original] → Restored from original MDX
```

### RAG Query Flow
```
User input → [optional: selected_context appended] → Embed query
→ Qdrant similarity search (top 5 chunks) → OpenAI completion with citations
→ Response streamed to chat widget → Citations displayed inline
```
